# Homelab Internal Domain (.internal) Setup Roadmap

## Phase 1: UniFi Network & DHCP Configuration
- Navigate to the UniFi Network Controller and select **Settings** > **Networks**.
- Choose your target network (e.g., your trusted VLAN).
- Expand **Advanced** / **DHCP Service Management**.
- Set the **Network Domain** (search suffix) to `internal` and save.
- Under **DHCP Server** settings for that network, disable **Auto** for DNS Server.
- Manually assign your Pi-hole static IP address as the primary DNS server for the network.
- Save and apply network changes.

## Phase 2: Pi-hole Authoritative DNS Configuration
- Log into your Pi-hole web administration interface.
- Navigate to **Local DNS** > **DNS Records**.
- Add the mapping for your local server:
  - Domain: `netone.internal`
  - IP Address: `192.168.2.20`
- Click **Add** to save the record.
- Repeat for any other homelab nodes requiring `.internal` resolution.
- Verify under **Settings** > **DNS** that upstream public resolvers are properly set for non-local traffic.

## Phase 3: Client Validation & Verification
- Force client devices to renew their DHCP lease and flush local DNS caches:
  - Windows: Run `ipconfig /release && ipconfig /renew && ipconfig /flushdns` in PowerShell.
  - Linux/macOS: Restart your network interface or flush local DNS resolvers.
- Run an explicit terminal lookup from a client machine to test resolution:
  ```bash
  nslookup netone.internal
